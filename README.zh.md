## 📝 项目简介

由 6 名学生组成的团队使用 Unity 引擎开发的 2D 平台跳跃游戏，采用看板敏捷开发方法论（Trello）。

> [!Note]
> 受课程时间限制，当前版本仅包含完整叙事中四个生物群系之一（沙漠）。本版本为可运行的**垂直切片（Vertical Slice）**，在第一个场景中完整展示了游戏机制、美术风格与完整游戏循环，作为项目最终愿景的概念验证。

## 📖 剧情与角色

游戏讲述了一只小企鹅的故事——它悠然仰躺在海面上小憩，却突然被海浪冲离家园，搁浅在一片荒芜的沙漠之中。醒来后，它发现自己迷失了方向，于是踏上了一段充满危险与挑战的旅程，立志回到北极的冰天雪地。

一路上，企鹅将穿越不同的环境，面对各种敌人与陷阱，挑战重重关卡，考验玩家的智慧与反应。
